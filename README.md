# Sonnensystem Live (solarsystem-3D)

Interaktives 3D-Sonnensystem im Browser. Die Planeten stehen an ihren echten, aktuellen Positionen, berechnet aus den Keplerschen Bahnelementen von NASA/JPL (gültig 1800–2050).

## Funktionen
- Echtzeit-Positionen aller 8 Planeten, Mond, Saturnringe, Achsneigungen
- Drehen, Zoomen, Planet antippen für Details (Abstand, Lichtlaufzeit, Bahngeschwindigkeit, Umlaufzeit)
- Zeitraffer vorwärts und rückwärts, «Jetzt» springt zur aktuellen Zeit
- Umschalten zwischen komprimiertem und echtem Distanz-Massstab

## Starten
Einfach `index.html` im Browser öffnen. Es braucht keinen Build, Three.js wird per CDN geladen.

Planetengrössen und der Mondabstand sind zur Sichtbarkeit vergrössert.
